# v0.2.0 security review

The review covers `arr-transport`, `security`, `scanner`, `quarantine`, `webhooks`, `auth`, `crypto`, branding/settings APIs, `job-queue`, runtime ownership and remediation journals. This is a repository review with isolated tests, not a third-party penetration-test certification.

- **SSRF / DNS rebinding:** restrict service URL schemes, reject userinfo/query/fragment and prohibited address ranges; validate all DNS answers and pin the chosen answer to the socket; never follow redirects. Private LAN services intentionally remain permitted for authenticated administrators. Tests cover IPv4/IPv6 aliases, mixed safe/unsafe DNS results, pinned lookup and redirect refusal.
- **Traversal / symlinks:** validate absolute paths and approved roots, canonicalize mapping/scan paths and reject escapes. Quarantine/restore additionally pin Linux parent descriptors and verify identities immediately before destructive actions. Tests cover directory swaps, symlink escapes, collisions, changed evidence, cancellation and EXDEV partial copies. Trusted mount ownership is required; no claim is made against a hostile host.
- **Webhook spoof / replay:** independent hashed bearer credentials per integration, constant-time checks, bounded/validated payloads, atomic receipt+job insertion and import identity deduplication. Tests cover wrong/revoked tokens, source mismatch, duplicate intake, invalid paths and generated-media queue execution. TLS protects bearer credentials in transit. Native intake does not use the older HMAC utility.
- **API-key leakage:** encrypted persistence; write-only public integration shape; generic connection/upload errors; transport errors omit response bodies and keys. Tests verify encryption tamper detection, public settings exclusion and non-disclosure of reflected remote response bodies. Administrators should still treat config backups as secrets.
- **Uploads / XSS:** bounded raster-only decode, MIME agreement, dimension/page checks, PNG re-encoding, generated names, exclusive writes, symlink-resistant reads, `nosniff` and restrictive asset CSP. Escaped React text and HTTP(S)-only Suite URLs; accent accepts hex only. Tests include disguised SVG, oversized/dimension-invalid payloads and trailing script removal. Public branding is intentionally visible on login.
- **SQLite / job concurrency:** parameterized queries, immediate transactions for deduplication/claim/receipts/retry reservations, lease-token fences, one bounded worker and one runtime per config. Cancellation revokes leases. Stale workers cannot finish or alter counts; recovery bounds attempts. Operation uniqueness and pre-dispatch states prevent uncertain external mutations from being repeated. Runtime-loss fencing and partial-failure tests remain mandatory release gates.

Production browser tests exercise authenticated administration and generated media on an internal mock network; dependency audit, repository secret scan, lint/typecheck, production build and container non-root/health checks complete the release gate. No live Arr, Plex, Jellyfin, Unraid or real media is needed or accessed by these tests.
